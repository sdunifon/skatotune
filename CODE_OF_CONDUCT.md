# Code of conduct

Skatotune adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, welcoming and constructive; critique ideas, not people; no harassment, discrimination or personal attacks, in any project space (issues, pull requests, discussions).

To report a problem, contact the maintainer privately through GitHub (for example via the maintainer's GitHub profile, or GitHub's private reporting if it is enabled for this repository). Reports are handled confidentially. The maintainer may remove content or block participants who violate this code.
